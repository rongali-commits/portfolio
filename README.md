# Earlier learning portfolio

[Current Noerong work](https://noerong.com/projects) · [Historical demo](https://chaitanya-rongali-portfolio.netlify.app/) · [LinkedIn](https://www.linkedin.com/in/rongalichaitanya)

An earlier portfolio built with HTML, CSS and JavaScript. It preserves five frontend learning projects and points visitors to the current Noerong studio.

## Implemented

- Responsive project-card grid with repository links
- Project thumbnails, technology labels and contact links
- Smooth navigation to page sections
- Automatically updated footer year

This version does not implement project filtering, a theme switch or a contact form. The repository remains archived as development history.

## Local preview

Serve this folder with any static HTTP server, for example `python -m http.server 8000`, then open `http://localhost:8000` locally.

`index.html`, `styles.css`, `script.js` and `thumb-nails/` form the static deployment. The thumbnails are the existing learning-project screenshots from the historical public site.
